## Overview

NocoBase is an open-source low-code platform for building business systems such as CRMs, with an Apache-2.0 core.

## Features

- Low-code platform
- Business system builder
- CRM building capabilities
- Apache-2.0 licensed core
- Self-hostable

## Pricing

Free and open-source under Apache-2.0 license.

## Deployment

Self-hosted via GitHub repository: https://github.com/nocobase/nocobase
