## Overview

BottleCRM is an open-source business CRM that combines sales, support tickets, and invoicing in a single application. Built on Django.

## Features

- Sales management
- Support ticket management
- Invoicing
- Built on Django
- Self-hostable

## Pricing

Free and open-source.

## Deployment

Self-hosted via GitHub repository: https://github.com/Django-CRM/Django-CRM
