## Overview

Frappe CRM is an open-source sales CRM for managing leads and deals. Built on the Frappe framework.

## Features

- Lead management
- Deal tracking
- Built on Frappe framework
- Self-hostable

## Pricing

Free and open-source.

## Deployment

Self-hosted via GitHub repository: https://github.com/frappe/crm
