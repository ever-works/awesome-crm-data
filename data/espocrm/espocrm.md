## Overview

EspoCRM is a CRM with a frontend designed as a single-page application and a REST API. It is written in PHP and licensed under AGPL-3.0.

## Features

- Single-page application frontend
- REST API for integration
- Self-hosted deployment
- Written in PHP

## Technical Details

- Language: PHP
- License: AGPL-3.0
- Repository: https://github.com/espocrm/espocrm
