## Overview

eWay-CRM is a Microsoft Outlook desktop add-on that extends Outlook with CRM capabilities for managing contacts, projects, deals, and notes directly from the email client.

## Key Features

- **Outlook Integration**: Desktop add-on for Microsoft Outlook (not available for Outlook on the web)
- **Contact Management**: Excel-like contact list with customizable columns
- **Company View**: Link contacts to their respective employers
- **Pipeline**: Board view with color-coded categories
- **Right-Click Conversion**: Convert emails to contacts, tasks, projects, or notes
- **Export**: Export data to Excel
- **Word Integration**: Document generation
- **Teams Integration**: Start Teams chats with right-click
- **Offline Mode**: Work without internet connection
- **Reports**: Group by, sort, filter for custom reporting

## Pricing

- **Free Plan**: Unlimited users and contacts
- **Paid Plans**: Start at $18/user/month (more storage, deeper project management, more customization)

## Deployment

Desktop add-on for Microsoft Outlook (Windows).
