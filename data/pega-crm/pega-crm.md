## Overview

Pega CRM is a proprietary customer relationship management platform originally developed by Chordiant. It provides CRM functionality for enterprises with AI-powered decisioning and process automation capabilities.

## Features

- Customer relationship management
- AI-powered decisioning
- Process automation
- Case management
- Customer data unification
- Omnichannel engagement
- Runs on Windows, Linux, Mac, and web browser

## Pricing

Proprietary licensing model. Pricing available from Pega sales.

## Deployment

Cross-platform deployment on Windows, Linux, Mac, and web browser.

## Integrations

- LDAP directory services
- Various enterprise systems via API

## Repository

Proprietary software; no public repository.
