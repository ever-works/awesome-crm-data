## Overview

NextCRM is an open-source CRM that includes projects, invoicing, and documents. Built with Next.js.

## Features

- Project management
- Invoicing
- Document management
- Built with Next.js
- Self-hostable

## Pricing

Free and open-source.

## Deployment

Self-hosted via GitHub repository: https://github.com/pdovhomilja/nextcrm-app
