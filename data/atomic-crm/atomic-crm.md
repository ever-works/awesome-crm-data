## Overview

Atomic CRM is an open-source business CRM for managing contacts, tasks, notes, and Kanban deal pipelines. Built with React, shadcn/ui, and Supabase for easy customization.

## Features

- Contact management
- Task management
- Notes
- Kanban deal pipeline
- Built with React, shadcn/ui, and Supabase
- Customizable
- Self-hostable

## Pricing

Free and open-source.

## Deployment

Self-hosted via GitHub repository: https://github.com/marmelab/atomic-crm
