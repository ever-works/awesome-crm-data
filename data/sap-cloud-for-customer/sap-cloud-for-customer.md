## Overview

SAP Cloud for Customer is a cloud-based customer relationship management platform by SAP SE, first released in 2009. It provides sales, service, and marketing capabilities delivered as a cloud service.

## Features

- Sales cloud
- Service cloud
- Marketing cloud
- Social media engagement
- Analytics and reporting
- Multi-language support
- Web-based interface
- Office integration
- Email attachment to business objects
- Global search
- Time tracking
- LDAP support

## Pricing

Proprietary SaaS licensing model. Enterprise pricing available from SAP sales.

## Deployment

Cloud-based (SaaS) deployment.

## Integrations

- SAP HANA
- SAP Cloud Platform
- SAP ERP
- LDAP directory services

## Repository

Proprietary software; no public repository.
