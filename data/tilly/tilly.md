## Overview

Tilly is an open-source relationship journal built as an offline-capable web application with client-side sync. It allows users to journal relationships and track interactions without requiring constant internet connectivity.

## Features

- Offline-capable web app
- Client-side sync
- Relationship journaling
- Interaction tracking
- Self-hostable

## Pricing

Free and open-source.

## Deployment

Self-hosted via GitHub repository: https://github.com/carlassmann/tilly
