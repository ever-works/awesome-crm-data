# Copper

## Overview
Copper is a CRM platform built specifically for Google Workspace users. It offers a full CRM feature set integrated directly with Google Workspace, providing native integration with Gmail, Google Calendar, and other Google apps.

## Key Features
- **Google Workspace integration**: full CRM feature set integrated with Google Workspace
- **Gmail integration**: work with CRM data directly from Gmail
- **Google Calendar integration**: schedule and track activities
- **Native Google apps integration**: work within the Google ecosystem

## Pricing
From $29/user/month.

## Deployment
Cloud (SaaS).

## Integrations
- Google Workspace (Gmail, Google Calendar, etc.)
- API available
- Zapier integration
