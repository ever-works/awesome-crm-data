## Overview

PingCRM is an open-source networking CRM that syncs with Gmail, Telegram, X (Twitter), and LinkedIn. It scores relationships and drafts follow-ups to help users manage professional networking.

## Features

- Gmail sync
- Telegram sync
- X (Twitter) sync
- LinkedIn sync
- Relationship scoring
- Follow-up drafting
- Self-hostable

## Pricing

Free and open-source.

## Deployment

Self-hosted via GitHub repository: https://github.com/sneg55/pingcrm
