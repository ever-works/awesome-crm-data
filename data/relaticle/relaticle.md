## Overview

Relaticle is a CRM with an MCP server, an AI assistant with human-approved changes, a REST API, custom fields, and kanban boards.

## Features

- MCP server integration
- AI assistant with human-approved changes
- REST API for integration
- Custom fields
- Kanban boards
- Docker deployment support

## Technical Details

- Language: PHP
- Deployment: Docker
- License: AGPL-3.0
- Repository: https://github.com/relaticle/relaticle
