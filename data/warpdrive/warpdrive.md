## Overview

Warpdrive is an open-source business development CRM modeled on Pipedrive. It features pipelines, a deal workspace, and two-way Gmail sync.

## Features

- Pipelines
- Deal workspace
- Two-way Gmail sync
- Modeled on Pipedrive
- Self-hostable

## Pricing

Free and open-source.

## Deployment

Self-hosted via GitHub repository: https://github.com/sneg55/warpdrive
