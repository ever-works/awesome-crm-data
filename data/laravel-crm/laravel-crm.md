## Overview

Laravel CRM is an open-source Laravel package that adds CRM features to an application or can run as a standalone CRM.

## Features

- Laravel package
- CRM features
- Can run as standalone CRM
- Self-hostable

## Pricing

Free and open-source.

## Deployment

Self-hosted via GitHub repository: https://github.com/venturedrake/laravel-crm
