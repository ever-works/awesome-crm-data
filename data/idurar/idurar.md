## Overview

IDURAR is an open-source ERP and CRM with accounting and invoicing. Built with Node.js and React.

## Features

- ERP
- CRM
- Accounting
- Invoicing
- Built with Node.js and React
- Self-hostable

## Pricing

Free and open-source.

## Deployment

Self-hosted via GitHub repository: https://github.com/idurar/idurar-erp-crm
